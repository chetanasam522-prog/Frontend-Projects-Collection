## Simon Says Game (Overview)

A browser-based memory game built with HTML, CSS, and JavaScript, where players must repeat an increasingly complex sequence of colors.
Simon Says is a classic pattern recognition game.
The system generates a random sequence of colors, and the player must replicate it correctly to progress to higher levels.

---

## Features

. Interactive color-based gameplay
. Random sequence generation
. Progressive difficulty (level-based)
. Instant feedback on user actions
. Game over detection with score display

---

## Tech Stack

. HTML5 – Structure
. CSS3 – Styling and animations
. JavaScript (Vanilla) – Game logic and interactivity

---

## Gameplay

. Press any key to start the game
. Observe the color pattern displayed
. Repeat the sequence by clicking the buttons
. Each level adds a new color to the sequence
. The game ends when an incorrect input is made

---

## Core Logic

. The system maintains a game sequence
. User inputs are stored in a user sequence
. Each input is validated step-by-step
. On success → next level
. On failure → game resets and score is displayed
